# resume-upload

前端工程师（实习）测评 — 上传简历页面，Vue 3 + Vite 实现。

## 运行

```bash
npm install
npm run dev       # 开发预览 http://localhost:5173
```

## 截图

生成到项目根目录（`screenshot-desktop.png` 桌面端 / `screenshot-mobile.png` 移动端）：

```bash
npm run screenshot
```

截图脚本会用系统已安装的 Edge / Chrome（无头模式）打开本地 dev server 并截取两种视口。

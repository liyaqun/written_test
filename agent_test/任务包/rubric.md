# Rubric —— 机房设备停机检修判定

判分对象为 agent 的两份提交物：`检修判定表.csv`（结构化）与 `判定说明.md`（自由文本）。
每条判分点都指向 `gold/` 中的具体位置，作为比对基准。

分值设计：**SV-001 为题眼**（额定上限为空、须回退到机柜级限值，最易漏判），
在「判定」「判定依据」「判定说明」三个维度上均加权，其余三台按普通分值。

## 类型与判定说明

- **程序化（R1~R12）**：由 `verifier/verify.py` 完全自动判定，无人工介入。
- **语义（S1~S4）**：本版不自动判定，`verify.py` 输出中标注「待人工/模型判定」；
  该部分分值计入总分上限，但不计入自动算出的当前总分。

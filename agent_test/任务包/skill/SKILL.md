# 规范判定类任务工作法

## When to use

当任务要求你「依据一份规则/规范文档，对一批记录逐条做出判定，并把判定结果与依据
填入表格、附一份判定说明」时，使用这套方法。典型形态：输入 = 一份规范 + 一批待判定记录 + 一张空表；输出 = 填好的表 + 判定说明。

## How to use

1. **先通读规范，列「判据清单」**：把规范里每一条可能触发判定的规则拆出来，逐条记下
   它的触发条件、有没有默认值/回退值、有没有例外或排除条件。不要跳过规范的脚注、
   补充句、括号说明——关键规则常藏在这些位置。

2. **标出「优先级」**：先找「排除类」规则（如「某状态下不参与本次判定」），这类规则
   通常要最先套用，它会使后续数值判断作废；再处理数值/阈值类规则。

3. **逐条套用，随手记录依据**：对每条记录，按优先级逐条检查判据，把「触发了哪一条 +
   用了哪个数值」当场写下来，作为「判定依据」。判定依据要写「条款 + 数值」，不要只写结论。

4. **特别注意「空值」**：某字段为空时，回到规范原文，找有没有「为空时改用什么」的说明，
   按说明取值；**不要看到空就跳过**。反过来，字段有值时，就按该字段自身判断，不要套用
   仅在「为空时」才启用的回退值。

5. **注意「覆盖/无条件」句式**：规范里出现「无论……都……」「即使……也……」这类表述时，
   说明该条是独立触发条件，不受其他条件是否满足影响，不能因为别的条件没满足就忽略它。

6. **输出前核对两件事**：① 判定值必须使用题目指定的枚举值，一字不差；② 判定依据里
   同时写清「触发条款号」与「关键数值」。表填完后再据此写判定说明，一机一段。

# 检修判定说明

依据《机房设备维护规范 v3.2》第 4 节「停机检修判据」及本期巡检数据，逐台判定如下。
套用优先级：先 4.3（排除类，状态为返修中即不纳入本次判定），再 4.2（无条件触发条款），
最后 4.1（温度阈值条款）。

## SV-001

- **判定：需检修**
- **触发条款：4.1**
- **依据数值：运行温度 64℃；通用计算机柜机柜级限值 62℃**
- **说明：** 该设备额定温度上限一列为空。按 4.1 补充句，该列为空的设备按其机柜级限值执行；
  本机机柜用途为「通用计算」，故取通用计算机柜限值 62℃。运行温度 64℃ > 62℃，
  温度超限，触发 4.1，判为需检修。（24h 告警 0 次，不触发 4.2；状态非返修中，不适用 4.3。）

## SV-002

- **判定：需检修**
- **触发条款：4.2**
- **依据数值：24h 告警次数 4 次；温度 66℃ 与额定上限 68℃ 未超限**
- **说明：** 该设备 24h 告警 4 次，≥ 3 次，触发 4.2。4.2 为无条件条款，明确「无论温度是否
  超限」均判需检修，因此即便运行温度 66℃ 未超其额定上限 68℃，仍判为需检修。
  （该设备额定温度上限有值，按该值自身判断，不套用机柜级回退限值；温度项未触发 4.1。）

## SV-003

- **判定：不适用**
- **触发条款：4.3**
- **依据数值：状态 =「厂商保修返修中」**
- **说明：** 该设备状态为「厂商保修返修中」，按 4.3 不纳入本次判定，判为「不适用」。
  4.3 为排除类条款，优先级最高，其后数值判断作废——故其运行温度 71℃ 虽已超额定上限
  68℃、24h 告警 2 次虽未达 3 次，均不再作为判定依据。

## SV-004

- **判定：需检修**
- **触发条款：4.1**
- **依据数值：运行温度 78℃；额定温度上限 75℃**
- **说明：** 该设备额定温度上限一列有值（75℃），按 4.1 正文以该列自身判断，不套用机柜级
  回退限值（本机虽属高密度 GPU 机柜，其 80℃ 限值仅在额定上限为空时才启用）。运行温度
  78℃ > 75℃，温度超限，触发 4.1，判为需检修。（24h 告警 0 次，不触发 4.2；状态非返修中，
  不适用 4.3。）

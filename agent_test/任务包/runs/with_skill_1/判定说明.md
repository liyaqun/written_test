# 机房设备检修判定说明

依据《机房设备维护规范 v3.2》第 4 节「停机检修判据」及《巡检数据.csv》，判定结果如下。

判定优先级：先套用排除类条款 4.3（状态为「厂商保修返修中」的设备不纳入判定），再套用数值/阈值类条款 4.2、4.1。

---

## SV-001（A-01，通用计算）

- **判定：需检修**
- **触发条款：4.1**
- **关键数值**：运行温度 64℃；额定温度上限列为空，按机柜级限值执行 → 通用计算机柜 62℃。
- **理由**：额定温度上限列为空，规范 4.1 规定「该列为空的设备，按其机柜级限值执行」，本机柜用途为通用计算，适用限值 62℃。运行温度 64℃ > 62℃，超过上限，触发 4.1。24h 告警 0 次，未达 4.2 的 3 次门槛。

## SV-002（A-02，通用计算）

- **判定：需检修**
- **触发条款：4.2**
- **关键数值**：24h 告警 4 次（≥3 次）；运行温度 66℃，额定温度上限 68℃。
- **理由**：运行温度 66℃ 未超过额定上限 68℃（额定列有值，不启用机柜回退值），故不触发 4.1。但 24h 告警 4 次 ≥3 次，按 4.2「无论温度是否超限，均判为需检修」，触发 4.2。

## SV-003（A-02，通用计算）

- **判定：不适用**
- **触发条款：4.3**
- **关键数值**：状态 = 厂商保修返修中；运行温度 71℃，额定温度上限 68℃。
- **理由**：本机状态为「厂商保修返修中」，4.3 属排除类条款，优先于数值判断：该设备不纳入本次判定，直接判为「不适用」。其运行温度 71℃ 虽已超额定上限 68℃，但按 4.3 不参与本次判定。

## SV-004（B-01，高密度 GPU）

- **判定：需检修**
- **触发条款：4.1**
- **关键数值**：运行温度 78℃，额定温度上限 75℃。
- **理由**：额定温度上限列为 75℃（有值），适用该值本身，不启用高密度 GPU 机柜回退限值 80℃。运行温度 78℃ > 75℃，超过上限，触发 4.1。24h 告警 0 次，未触发 4.2。

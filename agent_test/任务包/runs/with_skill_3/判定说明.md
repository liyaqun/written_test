# 机房设备检修判定说明

判定依据《机房设备维护规范 v3.2》第 4 节「停机检修判据」。判定优先级：先套用排除类条款 4.3，再套用数值/阈值类条款 4.1、4.2；4.2 为无条件触发条款，不受温度是否超限影响。

## SV-001（A-01，通用计算）——需检修

触发条款 4.1。该设备「额定温度上限」列为空，依据 4.1 的说明「该列为空的设备，按其机柜级限值执行」，回退到机柜级限值。机柜用途为通用计算，对应通用计算机柜限值 62 ℃。实际运行温度 64 ℃，64 ℃ ＞ 62 ℃，超过限值，判为需检修。24h 告警 0 次，未触发 4.2。

## SV-002（A-02，通用计算）——需检修

触发条款 4.2。24h 告警次数为 4 次，4 ≥ 3，达到告警阈值。依据 4.2「无论温度是否超限，均判为需检修」，此为无条件触发条款。其运行温度 66 ℃ 未超过额定温度上限 68 ℃（4.1 不触发），但不影响 4.2 的独立触发，仍判为需检修。

## SV-003（A-02，通用计算）——不适用

触发条款 4.3。该设备状态为「厂商保修返修中」，依据 4.3「不纳入本次判定，判为不适用」，作为排除类条款优先套用。虽运行温度 71 ℃ 已超过额定温度上限 68 ℃（本可触发 4.1），但按 4.3 该设备不参与本次判定，故数值判据作废，判定为不适用。

## SV-004（B-01，高密度GPU）——需检修

触发条款 4.1。该设备额定温度上限为 75 ℃（该列有值，直接按本行数值判断，不回退机柜级限值）。实际运行温度 78 ℃，78 ℃ ＞ 75 ℃，超过限值，判为需检修。24h 告警 0 次，未触发 4.2。

# 机房设备检修判定说明

- 判定依据：《机房设备维护规范 v3.2》第 4 节「停机检修判据」
- 巡检数据：`巡检数据.csv`
- 判定结果：`检修判定表.csv`
- 判定日期：2026-10-05

判据摘要：

- **4.1**　运行温度超过额定温度上限的，判为需检修。额定温度上限取巡检数据表对应行；该列为空的，按机柜级限值执行（通用计算机柜 62 ℃，高密度 GPU 机柜 80 ℃）。
- **4.2**　24 小时内告警 ≥3 次的，无论温度是否超限，均判为需检修。
- **4.3**　状态为「厂商保修返修中」的设备不纳入本次判定，判为「不适用」。
